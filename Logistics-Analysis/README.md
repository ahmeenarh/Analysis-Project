Logistics & Fleet Analysis Dashboard
Project Overview
This project analyzes logistics and fleet operations using Microsoft Excel and Power BI.
The analysis was designed to provide insights into fleet utilization, fuel expenses, driver performance, maintenance costs, delivery performance, operating costs, and estimated profitability.
Tools Used
•	Microsoft Excel
•	Power Query
•	Power BI
•	DAX
•	Data Modeling
•	Data Visualization
Dashboards
Dashboard 1 — Fleet & Operations Overview
Provides an overview of fleet operations and key performance indicators.
Dashboard 2 — Driver & Delivery Performance
Focuses on driver performance, trips, delivery performance, and operational efficiency.
Dashboard 3 — Cost & Profitability
Analyzes fuel expenses, maintenance costs, operating costs, and estimated profitability.
Key KPIs
•	Fleet Utilization Rate
•	Total Fuel Cost
•	Maintenance Cost
•	Driver Trips
•	On-Time Delivery Rate
•	Total Operating Cost
•	Estimated Profit
Key Skills Demonstrated
•	Data cleaning and transformation
•	Data modeling
•	Creating relationships between datasets
•	DAX calculations
•	KPI development
•	Interactive dashboard design

•	Data visualization
•	Business analysis
Project Goal
The goal of this project is to transform raw logistics data into meaningful insights that can help businesses monitor operational efficiency, control costs, evaluate performance, and make data-driven decisions.
